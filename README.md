# PyTrainer — учим Python с нуля до Telegram-бота

Десктоп-приложение для самостоятельного обучения Python. Под Windows готовый
`.exe` собирается автоматически через GitHub Actions — устанавливать ничего
не нужно, скачал и запустил.

## Что внутри

- **Курс** — 24 урока в 9 разделах, от «что такое Python и `print`» до
  первого Telegram-бота на `aiogram`.
- **Задачи** — пишешь код в редакторе, нажимаешь «Проверить», авто-тесты
  прогоняются в безопасной песочнице (отдельный процесс, таймаут).
- **«Показать решение»** — не просто код, а разбор «почему так».
- **Песочница / REPL** — запусти любой Python-код, посмотри вывод.
- **Заметки** — личная тетрадь, отдельно по каждому уроку.
- **Словарь терминов** — 40 терминов с поиском.
- **Карточки-квиз** — короткие вопросы на закрепление.
- **Геймификация** — XP, уровни, дневной стрик, достижения с уведомлениями.
- **Темы и шрифт** — тёмная/светлая, 4 размера шрифта, переключаются на лету.

## Программа курса

| Раздел | Что внутри |
|---|---|
| 0. Знакомство | Что такое Python, первый `print`, комментарии, ошибки |
| 1. Переменные | Создание, типы (`int`/`float`/`str`/`bool`), `input` и f-строки |
| 2. Условия | `if`/`elif`/`else`, операторы сравнения, `and`/`or`/`not` |
| 3. Коллекции | Списки и словари, основные операции |
| 4. Циклы | `for`, `while`, вложенные циклы |
| 5. Функции | `def`, `return`, `*args`/`**kwargs`, `lambda` |
| 6. Файлы и модули | `import`, `with open`, JSON |
| 7. pip и API | `venv`, `pip`, `requirements.txt`, HTTP-запросы |
| 8. Telegram-бот | Создание бота через `BotFather`, эхо-бот на `aiogram`, команды |

## Скачать готовый `.exe`

Готовые сборки для Windows публикуются автоматически после каждого пуша в
`main` в разделе **[Releases](../../releases)** (тег `latest`). Также `.exe`
лежит в **Artifacts** последнего успешного билда GitHub Actions
(вкладка Actions → последний run → Artifacts → `PyTrainer-windows`).

## Запуск из исходников (для разработки)

```bash
python -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -e .
pytrainer
```

## Структура

```
src/pytrainer/
├── __main__.py        # точка входа (умеет работать как worker для песочницы)
├── app.py             # главное окно, навигация, тосты, достижения
├── theme.py           # палитра + QSS (тёмная/светлая, font-scale)
├── progress.py        # сохранение JSON в %APPDATA%/PyTrainer
├── runner.py          # запуск пользовательского кода в subprocess
├── views/             # 8 экранов: home, lessons, sandbox, flashcards,
│                      #            notes, glossary, achievements, settings
├── widgets/           # CodeEditor (подсветка + номера строк), MarkdownView
└── content/           # уроки, задачи, словарь, карточки, достижения
```

Добавить новый урок — это просто новая запись в
`src/pytrainer/content/lessons.py`. Добавить задачу с авто-проверкой —
запись в `tasks.py` со списком тестов (`stdio` или `functional`).

## Где хранится прогресс

- Windows: `%APPDATA%\PyTrainer\progress.json`
- Linux: `~/.local/share/PyTrainer/progress.json`
- macOS: `~/Library/Application Support/PyTrainer/progress.json`

В настройках приложения есть кнопка «Сбросить весь прогресс» — обнуляет
уроки/задачи/XP/стрик, настройки темы и шрифта остаются.
